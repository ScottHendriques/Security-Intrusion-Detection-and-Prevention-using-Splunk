# Security Intrusion Detection and Prevention using Splunk SIEM

## 📌 Project Overview
A simulated enterprise security environment demonstrating real-world credential compromise, privilege escalation, and log aggregation. This project establishes local application-level logging and uses Splunk as a distributed SIEM to capture and alert on suspicious administrative activities.

## ⚡ Key Achievements
- **Exploit & Defense Simulation:** Configured a Damn Vulnerable Web Application (DVWA) to execute SQL injection attacks, bypassing authentication mechanisms.
- **Privilege Escalation Tracking:** Exploited broken access controls using browser DevTools to escalate user privileges to administrator, capturing restricted file exfiltrations (payslips).
- **SIEM Integration:** Integrated Splunk SIEM to aggregate distributed real-time logs, creating custom security dashboards and high-priority automated alerts for unauthorized access attempts.

## 🛠️ Tech Stack
- Splunk Enterprise (SIEM)
- DVWA (Damn Vulnerable Web Application)
- Linux / Local App Logging
